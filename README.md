# eSIM Landing

Лендинг СберМобайла на Vue 3, Vite и GSAP. Единственное приложение находится в корне репозитория.

## Актуальная версия и публикация

Единственная рабочая и production-ветка — `main`. Старые состояния доступны в истории Git.

- Исходники: https://github.com/ivanzl9208/esim-landing
- Production: https://esim-landing.layero.app/
- GitHub Pages: https://ivanzl9208.github.io/esim-landing/

Layero автоматически собирает push в `main` и публикует успешную сборку. GitHub Pages обновляется workflow `Deploy to GitHub Pages` из этой же ветки после тестов и сборки. `deployment.json` на Pages содержит SHA опубликованного коммита.

## Структура

- `src/components/` — Vue-компоненты интерфейса.
- `src/composables/` — состояние интерфейса и управление медиа.
- `src/animation/` — геометрия, тайминги и scroll-анимации.
- `src/data/` — тексты, FAQ и база устройств.
- `src/utils/` — поиск, типографика и вспомогательные функции.
- `src/styles/` — общие стили и доступность.
- `public/` — видео, изображения, шрифты и лицензии.
- `tests/` — автоматические проверки и браузерные стенды.
- `docs/` — описание архитектуры.

## Проверка и сборка

Требуется Node.js 20.19+ либо 22.12+. Команды выполняются из корня репозитория:

```sh
npm ci
npm test
npm run build
```

Локальный запуск:

```sh
npm run dev
```

Результат сборки — `dist/`. Зависимости зафиксированы в `package-lock.json`. `node_modules/`, `dist/` и локальные настройки не входят в репозиторий; разработчикам достаточно клонировать его и выполнить `npm ci`.

Тесты и браузерные регрессионные стенды в `tests/` сохранены для сопровождения scroll-анимаций, видео и поведения клавиатуры. Они не попадают в production-сборку. Небольшой `vercel.json` намеренно запрещает устаревшей интеграции Vercel запускать лишние деплои.

Подробнее об интеграции, медиа и известных ограничениях — [архитектура](docs/architecture.md).
