# eSIM Landing

Лендинг на Vue 3. Единственное приложение находится в [`vue/`](vue/README.md).

## Запуск

Требуется Node.js 20.19+ либо 22.12+.

```sh
cd vue
npm ci
npm run dev
```

Приложение доступно по адресу http://127.0.0.1:5174.

## Проверка и сборка

Из папки `vue/`:

```sh
npm test
npm run build
npm run preview
```

Готовая сборка — `vue/dist/`, локальный просмотр — http://127.0.0.1:4174.

## Структура

- `vue/src/` — компоненты, данные, стили и scroll-анимации.
- `vue/public/` — изображения, видео, шрифты и WebP-кадры.
- `vue/tests/` — автоматические тесты и браузерные стенды.
- `vue/package.json` и `vue/package-lock.json` — зависимости приложения.

Подробнее об архитектуре и проверках — в [документации Vue-приложения](vue/README.md).
