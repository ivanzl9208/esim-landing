# Работа с проектом eSIM

- Общаться по-русски, сохранять несвязанные изменения пользователя.
- Актуальное приложение находится в `vue/`; React в корне — прежняя версия.
- Запросы «Опубликуй» и «опубликовать» разрешают публикацию текущих изменений на оба адреса:
  - https://www.esim-landing.ivanzlobin.com/
  - https://ivanzl9208.github.io/esim-landing/
- Vercel больше не является целью публикации. Автодеплои Git отключены в корневом и Vue `vercel.json`; существующие проекты не удалять.
- Перед публикацией выполнить `npm test` и `npm run build` в `vue/`.
- Основной сервер eSIM: `135.106.175.20` (Россия), SSH-пользователь `root`; публикация готовой сборки — `bash scripts/deploy-host.sh`. Компоненты eSIM на прежних серверах `212.118.56.141` и `31.76.74.213` удалены 2026-10-05 по запросу пользователя; они больше не являются готовыми целями отката. VPN и общие сервисы FI сохранены. Сервер портфолио `135.106.228.161` не является целью публикации eSIM.
- Для GitHub проверить diff, включить только относящиеся к проекту изменения, создать коммит и отправить в `origin/main`; дождаться успешного workflow `Deploy to GitHub Pages`.
- На обоих адресах должна быть одна Vue-сборка. Проверить HTTP, файлы JS/CSS, картинки результатов и Range-запрос к видео.
- DNS основного поддомена `www.esim-landing.ivanzlobin.com`: A → `135.106.175.20`, Cloudflare DNS only (2026-10-05). Прежние `esim-landing.ivanzlobin.com` и `esim-landing-vue.ivanzlobin.com` остаются на том же RU IP и перенаправляют на основной адрес с сохранением пути и query. Не менять другие записи домена и не добавлять custom domain в GitHub Pages: оба адреса публикации должны работать независимо.
- На RU Nginx напрямую принимает HTTP 80 / HTTPS 443; `deploy/nginx.conf` установлен в `/etc/nginx/conf.d/esim-landing-vue.conf`. Один сертификат Let's Encrypt `www.esim-landing.ivanzlobin.com` покрывает все три eSIM-имени и продлевается Certbot через HTTP webroot `/var/www/esim-landing-vue/current`. Hook `deploy/reload-esim-nginx` установлен в `/etc/letsencrypt/renewal-hooks/deploy/reload-esim-nginx`. Nginx stream и VPN на FI не являются инфраструктурой публикации eSIM: их не изменять.
- Доступность проверять с внешнего подключения: полностью скачивать JS/CSS, картинки результатов и видео, а также проверять HTTP Range. Ответ 200 изнутри сервера или только на HEAD не подтверждает загрузку сайта у пользователей.
- Не записывать пароли, закрытые ключи и токены в репозиторий или документацию. Использовать существующий SSH-доступ; при отсутствии доступа запросить его у пользователя.
