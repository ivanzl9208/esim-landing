# Работа с проектом eSIM

- Общаться по-русски, сохранять несвязанные изменения пользователя.
- Единственное приложение проекта находится в корне репозитория. Его исходники, зависимости, тесты и ассеты самостоятельны.
- Перед публикацией выполнить `npm test` и `npm run build` в корне репозитория.
- Проверить diff, включить только относящиеся к задаче изменения. Не переписывать историю Git без отдельного запроса.
- Проверять результат с внешнего подключения: полностью скачивать JS/CSS, картинки результатов и видео, проверять HTTP Range. Ответ только на HEAD не подтверждает загрузку сайта у пользователей.
- Если существует `.codex/publish.local.md`, прочитать дополнительные локальные инструкции перед публикацией. Этот файл не предназначен для репозитория.
- Не записывать пароли, закрытые ключи и токены в репозиторий или документацию.
